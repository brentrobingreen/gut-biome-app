# gut_biome_app

A collection of web-based games and tools, starting with a coin flip game.

## Git workflow (required for every session)

After every meaningful code change:
1. Stage the relevant files by name (never `git add -A` or `git add .` blindly)
2. Commit with a clean, imperative-mood message under 72 characters (e.g. `Add score reset animation`, `Fix coin landing on wrong face`)
3. Push immediately: `git push origin main`

The GitHub remote is `https://github.com/brentrobingreen/gut-biome-app`.
